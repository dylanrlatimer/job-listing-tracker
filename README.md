# Job Listing Tracker

A WordPress application for organizing a job search around companies and their relevant positions.

## Local development

Requirements: Node.js LTS, Docker Desktop, and Git.

```powershell
npm install
npm run env:start
```

Open `http://localhost:8888`. The local administrator credentials are `admin` and `password`.

Stop the environment with:

```powershell
npm run env:stop
```

Project scope and schema are documented in `docs/`.
