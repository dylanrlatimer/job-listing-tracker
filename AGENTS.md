# Project instructions

Before planning or editing code, read these files in order:

1. `docs/APP-OUTLINE.md`
2. `docs/SCHEMA.md`

Treat `APP-OUTLINE.md` as the authority for scope and architecture. Treat `SCHEMA.md` as the authority for storage, fields, relationships, ownership, validation, and deletion.

Do not replace documented decisions with a different architecture without explicit approval.

Work only on the requested milestone. Preserve unrelated code and user changes. Run the relevant checks before reporting completion.

Keep version 1 small. In particular, do not add custom database tables, taxonomies, a membership suite, a front-end framework, custom Gutenberg blocks, or ACF forms for private tracking.
