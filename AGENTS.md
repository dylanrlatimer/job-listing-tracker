# Project instructions

Before planning or editing code, read these files in order:

1. `docs/APP-OUTLINE-v2.md`
2. `docs/SCHEMA-v3.md`

Treat `APP-OUTLINE-v2.md` as the authority for scope and architecture. Treat `SCHEMA-v3.md` as the authority for storage, fields, relationships, ownership, validation, and deletion.

Do not replace documented decisions with a different architecture without explicit approval. Do not edit a versioned planning document in place. When asked to revise one, create the next numbered version.

Work only on the requested milestone. Preserve unrelated code and user changes. Run the relevant checks before reporting completion.

Keep version 1 small. In particular, do not add custom database tables, taxonomies, a membership suite, a front-end framework, custom Gutenberg blocks, or ACF forms for private tracking.
